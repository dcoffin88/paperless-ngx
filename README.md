**Personal-use fork of Paperless-ngx that adds a PDF flipbook viewer.**

# Paperless-ngx

Paperless-ngx is a document management system that transforms your physical documents into a searchable online archive so you can keep, well, _less paper_.

# Getting started

To deploy this modified paperless use `docker compose`. The files in the [`/docker/compose` directory](https://github.com/dcoffin88/paperless-ngx/tree/dev/docker/compose) are configured to pull the image from the GitHub container registry.
